# 推力，向哪里去？

一个中文 eVTOL 飞行原理交互演示，用等距 SVG 剖视图解释电池、电控、电机、涵道风扇与飞行控制如何配合。

## 使用

直接在浏览器中打开 `index.html`，无需构建或安装依赖。也可通过仓库的 GitHub Pages 地址在线访问。

- 调整总推力与风扇倾角。
- 切换悬停、前飞、横滚，观察推力分量。
- 对照风扇盘面近竖直的示意，理解为什么水平推力无法直接支撑悬停。
- 打开机身剖视并查看各部件说明。
- 支持手机布局、键盘操作以及减少动态效果设置。

## 模型与限制

六风扇对称布局、独立电机与可倾转轴线均为教学假设，不是对某一真实机型的工程复刻。原始参考图片未包含在本仓库中。

总推力以重力 W 归一化。未横滚时，垂直分量为 `T cosθ`，水平分量为 `T sinθ`，垂直净加速度为 `g (T cosθ / W − 1)`；横滚时再计入倾斜的余弦分量。取 `g = 9.81 m/s²`。

横滚姿态仅表示差动推力造成的趋势，不求解真实姿态动力学。模型忽略机翼升力、阻力和地面效应，不预测速度、航程、功耗或安全性，不用于实际飞行控制。
